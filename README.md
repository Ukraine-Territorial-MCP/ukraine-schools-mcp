# Ukraine Schools MCP

MCP-сервер для отримання відкритих даних про заклади освіти України, їхню територіальну належність і фінансування освіти.

## Джерела даних

- **ЄДЕБО** — інформація про заклади освіти, керівників, адреси та контакти.
- **КАТОТТГ** — області, райони, територіальні громади та населені пункти.
- **Open Budget** — планові та фактичні видатки на освіту.

## MCP-інструменти

### get_school_info

Отримання інформації про конкретний заклад освіти за його кодом ЄДЕБО.

Параметр: `school_id`.

### list_schools_by_community

Отримання переліку закладів освіти громади за кодом КАТОТТГ.

Параметр: `community_code`.

### get_education_budget

Отримання бюджетних показників за освітніми програмами.

Параметри:
- `budget_code` — код місцевого бюджету;
- `year` — бюджетний рік.

## Технології

- Python 3.12
- MCP Streamable HTTP
- Ukraine Data Engine 0.1.0

## Запуск

Основний застосунок: `server:app`.

Приклад локального запуску після встановлення залежностей:

```bash
uvicorn server:app --host 127.0.0.1 --port 8915
```

MCP endpoint: `/mcp`.

## Залежності

Ukraine Data Engine наразі є приватною бібліотекою.

Цей репозиторій містить код MCP-сервера, але для
самостійного розгортання потрібен окремий доступ
до бібліотеки Ukraine Data Engine та каталогу КАТОТТГ.

## Тестування

Публічні структурні тести:

```bash
python3 -m unittest discover -s tests -v
```

Повний інтеграційний тест виконується в середовищі
з установленим Ukraine Data Engine.

## Статус

Version 1.0 — три MCP-інструменти перевірені.

Публічна HTTPS-адреса та реєстрація в MCP Registry
будуть додані після розгортання.
